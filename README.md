# CCAR-P Study Guide — Claude Certified Architect, Professional

Complete study materials for Anthropic's professional-tier Claude certification (exam code CCAR-P), built from the official exam guide v1.0 (effective July 2026).

## Exam at a glance

- 63 items: multiple-choice and multiple-response (each item states how many to select)
- 120 minutes, proctored via Pearson VUE (online or test center)
- Pass: 720 on a 100–1,000 scaled scale · Fee: $175 · Valid 12 months

## How the exam asks

Scenario-based design decisions and trade-offs — not config trivia. Multiple-response items state exactly how many answers to select. Distractors are "most correct" style: several options are partially right; the credited answer best satisfies the stated constraint (accuracy SLA, latency budget, compliance rule, cost ceiling). Read constraint-first.
